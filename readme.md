# Part 1: Initalizing the game
I started by initalizing and getting the game basics done, such as the background with stars or the players spaceship.

# Part 2: Controls
After setting up the background, I added controls with the keyboard and mouse. This includes the ship following the mouse and the arrow keys controlling the direction of the player. Additionally, I switched to Sprites, which is more organized.

# Part 3: Code efficiency
Obviously, not using sprites is a bad idea. To fix this, I switched to sprites to make the code a lot better in terms of speed and organization.

# Part 4: Meteors and lasers
For this part, I added functional shooting and meteors that spawn. Additionally, I added a timer so that the player can't shoot too fast and meteors can't spawn instantly.

# Part 5: Collisions
After adding the elements, I added collisons, which is a key part of the game. The game is fully functional, but it is still very lacking style.

# Part 6: Styling & Sound
After finishing the main functions of the game, I added a box tracking the score and played around with the color. Additionally, I added sound and rotating asteroid features. Overall, this part was just making the game look better, but didn't actually change any of the functionality.

This game is one in the series of games I will be building with pygame. As the games go on, they will get more and more complex.
